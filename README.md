# Michaela Vivant Photography

A responsive photography portfolio website built for a freelance client. The site showcases the photographer's work, services, and pricing, and allows potential clients to reach out directly via a contact form.

🔗 **Live Site:** [michaelavivant.com](https://michaelavivant.com)

---

## Features

- **Portfolio Gallery** — Displays the photographer's work in a clean, visual layout
- **Pricing Section** — Outlines available packages and services
- **About Page** — Introduces the photographer and her story
- **Contact / Inquiry Form** — Allows visitors to submit booking inquiries directly to the photographer's email
- **Fully Responsive** — Optimized for mobile, tablet, and desktop

---

## Tech Stack

- **React** — Component-based UI
- **JavaScript** — Application logic
- **Tailwind CSS** — Utility-first styling and responsive design
- **Vercel** — Deployment and hosting

---

## Project Overview

This was a freelance project where I handled the full delivery — from initial requirements gathering with the client through design, development, and production deployment. The goal was to create a professional, visually clean site that reflects the photographer's brand and makes it easy for potential clients to explore her work and get in touch.
